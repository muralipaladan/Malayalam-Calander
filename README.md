# Malayalam Panchangam Calendar (മലയാള പഞ്ചാംഗം കലണ്ടർ)

A modern Android application built with Kotlin, Jetpack Compose, and Material Design 3, providing an astronomical Malayalam Panchangam calendar based on Drik Ganitha and Lahiri Ayanamsa calculations.

## Key Features

- **Panchangam Calculations**:
  - 27 Nakshatras (അശ്വതി, ഭരണി, etc.) with precise transition times in Indian Standard Time (IST).
  - 30 Tithis across Shukla Paksha and Krishna Paksha.
  - 12 Malayalam Solar Months (ചിങ്ങം, കന്നി, തുലാം, etc.) with Kollavarsham year calculation.
  - Nirayana Sun and Moon Longitude calculations with Lahiri Ayanamsa.
- **Interactive Calendar Grid**:
  - Full monthly view with Gregorian dates, Malayalam dates, Nakshatra, and Tithi.
  - Accordion day expansion showing comprehensive planetary and lunar information.
  - Quick month navigation, fast jump to today, and year-month picker.
- **Local Persistence & Reminders**:
  - On-device Room database persistence for user notes, event reminders, and tasks.
  - Time tagging, completion checkmarks, and notification toggles.
  - Global reminders bottom-sheet modal grouped chronologically by date.
